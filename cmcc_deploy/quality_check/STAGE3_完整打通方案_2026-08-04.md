### 模块 3：多 GPU 调度器

**设计目标**：48 GPU 并行，均衡负载

```python
# 伪代码
class Stage3Scheduler:
    def __init__(self, num_gpus=48):
        self.num_gpus = num_gpus
        self.workers = []
    
    def distribute_workload(self, sample_list):
        """将样本均匀分配到 48 个 GPU"""
        samples_per_gpu = len(sample_list) // self.num_gpus
        workload = []
        for gpu_id in range(self.num_gpus):
            start = gpu_id * samples_per_gpu
            end = start + samples_per_gpu if gpu_id < self.num_gpus - 1 else len(sample_list)
            workload.append({
                'gpu_id': gpu_id,
                'samples': sample_list[start:end],
                'output_file': f'/root/work/david_work/qc_output/stage3/worker_{gpu_id:02d}.jsonl'
            })
        return workload
    
    def launch_workers(self, workload):
        """启动 48 个独立 worker 进程"""
        for job in workload:
            cmd = [
                'python', '-m', 'sana_wm_pipeline.qc.stage3_gpu',
                '--gpu-id', str(job['gpu_id']),
                '--sample-list', json.dumps(job['samples']),
                '--output', job['output_file'],
            ]
            # 使用 subprocess 启动后台进程
            pass
```

### 模块 4：进度监控与日志

```python
# 实时监控脚本
class Stage3Monitor:
    def __init__(self, output_dir, total_samples):
        self.output_dir = Path(output_dir)
        self.total_samples = total_samples
    
    def get_progress(self):
        """统计已完成样本数"""
        completed = 0
        for jsonl_file in self.output_dir.glob('worker_*.jsonl'):
            with open(jsonl_file) as f:
                completed += sum(1 for _ in f)
        return completed, self.total_samples
    
    def estimate_remaining_time(self, start_time):
        """预估剩余时间"""
        completed, total = self.get_progress()
        if completed == 0:
            return None
        elapsed = time.time() - start_time
        rate = completed / elapsed  # 样本/秒
        remaining = (total - completed) / rate
        return remaining / 3600  # 转换为小时
```

## 🔍 关键决策点

### 决策 1：分辨率选择

**选项**：
- **A**: 256×256（当前测试配置）
  - 优势：速度最快（28 ms/帧对）
  - 劣势：细节损失，可能影响质量评估准确性
  
- **B**: 480×480
  - 优势：平衡速度与质量
  - 劣势：推理时间增加至 ~100 ms/帧对
  
- **C**: 原始分辨率（720p/1080p）
  - 优势：评估最准确
  - 劣势：推理时间增加至 ~200+ ms/帧对

**建议**：先用 256×256 跑通全流程，如质量不满意再用 480×480 重跑

---

### 决策 2：Caption 改写策略

**当前实现**：
- 仅对包含相机词汇的 caption 进行改写
- 改写通过 Qwen3.5-9B VLM（使用关键帧）

**问题**：
- 如何判断 caption 是否包含相机词汇？
  - 方案 A：简单关键词匹配（快速但可能漏检）
  - 方案 B：所有 caption 都过 VLM（准确但慢）

**建议**：先用关键词匹配，减少 VLM 调用次数

### 决策 3：失败重试策略

**可能的失败原因**：
- GPU OOM（显存不足）
- 视频文件损坏
- 模型推理超时
- 网络存储 I/O 错误

**重试策略**：
```python
MAX_RETRIES = 3
RETRY_DELAYS = [5, 30, 300]  # 5秒, 30秒, 5分钟

for attempt in range(MAX_RETRIES):
    try:
        result = process_sample(sample_id)
        break
    except GPUOutOfMemoryError:
        torch.cuda.empty_cache()
        time.sleep(RETRY_DELAYS[attempt])
    except FileNotFoundError:
        logger.error(f"Sample {sample_id} video file not found")
        result = {"error": "file_not_found"}
        break
    except Exception as e:
        logger.error(f"Attempt {attempt+1} failed: {e}")
        if attempt == MAX_RETRIES - 1:
            result = {"error": str(e)}
```

## 🚨 风险与缓解措施

### 风险 1：数据路径不一致

**风险**：Stage 1+2 使用的数据路径与 Stage 3 不一致

**缓解**：
- 在阶段 B 的单样本测试中彻底验证路径映射
- 提供路径映射配置文件，支持灵活调整

---

### 风险 2：显存溢出（GPU OOM）

**风险**：某些超长视频或高分辨率视频导致 OOM

**缓解**：
- 设置 `max_frames` 限制（如最多处理 300 帧）
- 对超长视频降采样处理
- 实现自动重试机制（降低分辨率重试）

---

### 风险 3：I/O 瓶颈

**风险**：48 个 worker 同时读取网络存储，导致 I/O 拥堵

**缓解**：
- 将热数据复制到本地 SSD（如果有）
- 实现数据预加载缓存机制
- 错峰启动 workers（每秒启动 2-3 个）

---

### 风险 4：执行中断

**风险**：7-8 小时执行过程中可能因网络/机器问题中断

**缓解**：
- 实现断点续传：已完成的样本不重复处理
- 定期（每小时）检查点，保存进度
- 设置自动重启脚本

```python
# 断点续传逻辑
def load_completed_samples(output_dir):
    """加载已完成的样本 ID"""
    completed = set()
    for jsonl_file in Path(output_dir).glob('worker_*.jsonl'):
        with open(jsonl_file) as f:
            for line in f:
                sample = json.loads(line)
                completed.add(sample['sample_id'])
    return completed

def filter_pending_samples(all_samples, completed_samples):
    """过滤出待处理样本"""
    return [s for s in all_samples if s not in completed_samples]
```
