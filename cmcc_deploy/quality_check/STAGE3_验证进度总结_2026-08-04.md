## 🔧 关键技术决策

### 1. UniMatch 推理参数

**问题**：参数长度必须匹配 `num_scales=2`

**解决方案**：
```python
INFERENCE_PARAMS = {
    'attn_type': 'swin',            # 必需
    'attn_splits_list': [2, 8],     # 长度 = 2
    'corr_radius_list': [-1, 4],    # 长度 = 2
    'prop_radius_list': [-1, 1],    # 长度 = 2
}
```

### 2. Qwen3.5 模型加载

**问题**：新架构需要 transformers 5.x

**解决方案**：
```python
# 使用 Auto 类 + 升级 transformers
from transformers import AutoModelForCausalLM
model = AutoModelForCausalLM.from_pretrained(
    MODEL_PATH,
    dtype=torch.bfloat16,  # 新参数名
    device_map="auto",
    trust_remote_code=True
)
```
