# 紧急修复：降采样未生效问题

## 🔍 问题确认

CMCC 测试结果显示：
```
[2/7] 视频解码: 1190.19 ms
      帧数: 160, 分辨率: 720x1280    ← ❌ 应该是 480x640
```

**问题**：降采样功能没有生效，仍然使用原始 720p 分辨率，导致 OOM。

---

## 🔧 根本原因

在 `stage3_gpu.py` 第 132 行，调用 `_decode_frames` 时**没有传递 `max_resolution` 参数**：

```python
# ❌ 错误：没有传递 max_resolution
frames_rgb = _decode_frames(mp4_bytes)
```

虽然 `_decode_frames` 函数已经支持降采样，但调用处没有使用。

---

## ✅ 修复方案

### 修改位置

**文件**：`src/sana_wm_pipeline/qc/stage3_gpu.py`  
**行号**：第 132 行

### 修改内容

**旧代码**：
```python
frames_rgb = _decode_frames(mp4_bytes)
```

**新代码**：
```python
# 解码视频帧（自动降采样到 480p）
frames_rgb = _decode_frames(mp4_bytes, max_resolution=640)
```

### 如果仍然 OOM

如果修复后仍然 OOM（可能性很小），进一步降低分辨率：


`max_resolution` 参数说明：

| 值 | 约等分辨率 | 显存需求 | 精度影响 | 推荐度 |
|----|----------|---------|---------|--------|
