## 🎯 使用建议

### 推荐训练策略

#### 策略 A：渐进式训练（推荐）

**阶段 1**：用 v1.0（1,980 样本）建立高质量基线
- 样本：3 个真实数据集的 excellent + good
- 目标：确保模型基础质量

**阶段 2**：用 v1.1（2,651 样本）提升鲁棒性
- 样本：加入 acceptable 评级
- 目标：增强模型对中等质量数据的处理能力

**阶段 3**：用 v1.2（4,720 样本）扩大规模
- 样本：加入 DL3DV-ALL-2K
- 目标：提升样本多样性和泛化能力

#### 策略 B：直接使用 v1.2（适合大规模训练）

**适用场景**：
- ✅ 计算资源充足（可以训练 4,720 样本）
- ✅ 希望一次性获得最大样本量
- ✅ 需要多样化场景（3D 重建场景 + 真实场景）

**质量加权建议**：
```python
sampling_weights = {
    'excellent': 1.0,
    'good': 0.8,
    'acceptable': 0.5
}
```

#### 策略 C：数据集组合训练

**组合 1**：仅真实场景（v1.1）
- 样本：2,651
- 数据集：RealEstate10K + SpatialVID-hq + sekai-real-walking-hq
- 优势：真实世界物理规律一致

**组合 2**：真实 + 3D 重建（v1.2）
- 样本：4,720
- 数据集：上述 3 个 + DL3DV-ALL-2K
- 优势：样本量最大，场景多样性最强

## ⚖️ 版本选择指南

### 三个版本对比

| 场景 | 推荐版本 | 理由 |
|------|---------|------|
| **追求最高质量** | v1.0 | 仅 excellent + good，质量最优 |
| **平衡质量与数量** | v1.1 | 加入 acceptable，质量可控 |
| **需要最大样本量** | v1.2 | 加入 DL3DV，样本量翻倍 |
| **真实场景专注** | v1.1 | 不含 3D 重建数据 |
| **3D 场景理解** | v1.2 | 包含 DL3DV 3D 重建场景 |
| **计算资源有限** | v1.0 或 v1.1 | 样本量较小 |
| **大规模训练** | v1.2 | 充分利用数据 |

### 混合使用建议

**方案 1：质量优先**
1. 用 v1.0 训练核心模型
2. 用 v1.1 - v1.0 的增量微调
3. 评估是否需要 v1.2

**方案 2：规模优先**
1. 直接用 v1.2 训练
2. 按质量分层评估效果
3. 如效果不佳，降级到 v1.1

**方案 3：数据集组合**
1. 先用真实场景（v1.1）训练
2. 再用 DL3DV 单独微调
3. 观察 3D 重建数据的影响
